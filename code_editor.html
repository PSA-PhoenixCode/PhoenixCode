This is text-based Scratch syntax. Example: when green flag clicked repeat 10 move 10 steps end Scratch-style control blocks use indentation plus end. end loop ends the nearest repeat/forever loop. end script stops the entire running script. Expressions can use variables: set score to 10 change score by 1 set result to score + 5 Code uses Scratch-style text blocks, and the Costumes tab is a vector SVG editor with SVG import.
